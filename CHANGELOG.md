## Unreleased

### Fixed

- `render-agent-commands.ts`: the description-folding filter dropped every
  `[cc: alias]` line before its prefix could be stripped, truncating or
  falling back to a generic description for all 21 generated Codex skills and
  Gemini TOML commands. The frontmatter/body regexes also assumed LF line
  endings; the Cursor source files are CRLF, so the fence never matched and
  the body silently kept its raw YAML frontmatter block.
- Codex-generated skills baked in Cursor's colon slash-command spelling
  (`/cc:x`) for cross-references to other commands; Codex only understands
  `$cc-x`. Hand-written OpenCode and AGY command files had the same leftover
  colon spelling where they should read `/cc-x`.
- `agy` global preset install: `antigravity-cli/settings.json` was routed
  through `.agents/../antigravity-cli/settings.json`, which always resolved
  outside its containment root and refused the write. It now resolves
  against `~/.gemini` directly, matching `presets/agy/README.md`.
- `agy` hooks: `PreToolUse` fired on every file read (`view_file`), and the
  hook runner could emit two concatenated JSON documents on stdout when a
  candidate CLI wrote partial output before failing, corrupting the verdict
  the agent tries to parse.
- `substituteToolNames` hardcoded `\n` when rewriting frontmatter, silently
  converting CRLF files' frontmatter boundary to LF while the rest of the
  file stayed CRLF.
