### Added

- `goal` command (alias: `cc-goal`) — decomposes an objective string into a
  dependency-ordered task graph using template matching (auth, crud, search,
  notification, migration) with generic fallback. Writes
  `.codeconductor/current-goal.yml` for orchestrator consumption.
- `goal-planner` agent — deterministic template matching, produces YAML task
  graph with explicit `depends_on` references.
- `src/core/goal/` module — `goal-planner.ts` (template matching) and
  `goal-state.ts` (graph validation, cycle detection, YAML persistence).
- `depends_on` field in Task Card template — optional list of task IDs for
  dependency-ordered delegation by the orchestrator.
- Dependency-order delegation rules for orchestrator — tasks are routed only
  after all `depends_on` targets complete with status `done`.
