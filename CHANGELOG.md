## Unreleased

### Changed

- Parse native Claude and Antigravity hook stdin, replay input across runner
  fallbacks, normalize Windows paths and Git executables, and run local
  formatters through Node without npm shell shims. Claude permissions now
  default to `default`.
- Use the four requested OpenCode Go models with compatible permission rules and
  provider sampling defaults; correct Antigravity CLI model slugs.
- Use portable lowercase skill names across canonical, preset, and installed
  skills, with regression validation and hook CI on Linux, macOS, and Windows.
- Extended the 20 `security-*` skills to Codex; promoted `code-review`,
  `seo-analytics-injector`, and `tdd-mutation-tester` to all five targets;
  added 11 stack skills (astro, auth-token-inspector, django-uv,
  drizzle-schema-architect, fastapi-pydantic-strict, jpa-nplusone-detector,
  livewire-alpine-bridge, nextjs-typescript, spring-auth-auditor,
  spring-boot-testing-strategy, tailwind-responsive-auditor) to Claude, Codex,
  and Antigravity, sourced from the Cursor-less opencode variant; promoted
  `python`, `django-orm`, `spring-boot-feature`, `jpa-postgres`, and
  `api-versioning` to canonical shared skills across all five targets,
  fixing formatting drift between the claude/opencode copies.
- Extended `classifyRisk()`'s high-risk pattern with infrastructure and
  supply-chain signals (alembic, CI/CD workflow files, Dockerfile/terraform,
  dependency lockfiles).
- Added a Severity Rubric to `/cc:review` anchoring CRITICAL/WARNING/SUGGESTION
  to concrete conditions instead of general judgment, applied across all seven
  runners and referenced from `docs/agent-scorecard.md`.
- `detectComplementaryTools()` now probes its six optional tools concurrently
  (promisified `execFile`) instead of sequentially, cutting the worst-case
  `doctor`/`install`/`update` stall from ~6s to ~1s.

### Added

- Receipt-Driven Development receipts for local verification, TDD transitions,
  OpenSpec gates, ODD resumption, and Council candidate comparison.

- `/cc-security` (`/cc:security`) — authorized defensive security workflow with
  an authorization gate and risk-based routing.
- Shared `web-design-engineering` skill for contextual web UI design, implementation,
  and review across all seven runners, with conditional workflow references,
  accessibility and motion criteria, and explicit pending visual verification.
- Shared `android-ui-design` skill for contextual Jetpack Compose phone UI design,
  implementation, review, and read-only audits across all seven runners.
- `.gitattributes` enforcing `eol=lf` on checkout, preventing Windows
  `core.autocrlf` from reintroducing CRLF into shipped preset sources.
- `test/unit/core/ccep/risk-classifier.test.ts` — explicit signal matrix for
  `classifyRisk()`, covering every HIGH_RE and infrastructure pattern plus all
  type-based rules.

### Fixed

- Windows-incompatible path handling: `basename()`/`relative()` replace
  `split('/')` in the knowledge source parsers, ingest pipeline, and CCEP
  command parser; `join()` replaces string concatenation for the workflow
  loop's test-freeze lock path.
- Cursor, OpenCode, and Antigravity's `security`/`pagespeed`/`openspec`
  commands referenced `.claude/skills/...` regardless of the installed
  target; corrected to each target's actual skill path (`.cursor/skills/`,
  `.opencode/skills/`, `.agents/skills/`), with Gemini and Codex regenerated
  through a new `rewriteSkillsPath()` render step.
- Removed the dangling reference to a non-existent
  `pagespeed-perf/scripts/run.ts` script from the pagespeed workflow (cursor
  origin, opencode, and the agy skill and workflow copies).
- Removed a stray reasoning-trace comment left in `test-freeze.ts` and
  documented that its only consumer is the experimental `runWorkflowPipeline()`
  loop, not the production RDD verification gate.
