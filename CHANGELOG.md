## Unreleased

### Added

- **`complexity-auditor` agent** — analyzes diffs for bloat, unnecessary abstractions, non-native solutions, and unused imports; produces a `ComplexityAuditReport` with LOC, dependency, and cyclomatic complexity deltas (`src/core/complexity/complexity-auditor.ts`, `src/core/complexity/types.ts`)
- **`computeCcGain()` function** — computes cc-gain score from audit report using formula: `(locRemoved * 0.4) + (depsAvoided * 1.5) + (complexityReduced * 2.0) - (abstractionFindings * 1.0)`, normalized to [-1, +1] with positive/neutral/negative verdict (`src/core/complexity/cc-gain.ts`)
- **Scorecard criterion #8: Complexity Diffusion (cc-gain)** — 5% weight, driven by `complexity-auditor` output; maps verdict to 0–3 score (`docs/agent-scorecard.md`)
- **`help` / `cc-help` command** — shows preset inventory (skills, subagents, commands, workflows) for the active or specified target by scanning `presets/<target>/` (`src/commands/help.command.ts`)
- **`debt-harvest` / `harvest` command** — scans source files for `// defer - [reason]` comments and writes a consolidated `.codeconductor/debt-ledger.md` grouped by optional tag (`src/commands/debt-harvest.command.ts`)
- **`CodexAgentContractRenderer`** — renders contracts into `.codex/` structure with format validation (`src/adapters/codex/agent-contract-renderer.ts`)
- **`AgyAgentContractRenderer`** — renders contracts into `.agents/` structure with format validation (`src/adapters/agy/agent-contract-renderer.ts`)
- **AgentContract abstraction** — provider-agnostic contract type (`AgentContract`, `createAgentContract()`) that wraps a `CouncilSpec` with targeting and versioning metadata (`src/domain/council/agent-contract.ts`)
- **`toAgentContract()` helper** — convenience function on `CouncilSpec` to convert a spec into an `AgentContract` for one or more targets (`src/domain/council/council-spec.ts`)
- **Council consensus engine** — pure function `councilConsensus()` that computes a verdict from N reviewer agents using majority or unanimous algorithms, with security veto support (`src/domain/council/council-consensus.ts`)
- **`AgentContractRenderer` interface** — strategy interface for rendering an `AgentContract` into provider-specific files (`src/core/generation/agent-contract-renderer.ts`)
- **`ClaudeAgentContractRenderer`** — renders contracts into `.claude/` structure with format validation (`src/adapters/claude/agent-contract-renderer.ts`)
- **`OpenCodeAgentContractRenderer`** — renders contracts into `.opencode/` structure with frontmatter and format validation (`src/adapters/opencode/agent-contract-renderer.ts`)
- **Zod validation schemas** — `AgentContractSchema`, `CouncilVerdictInputSchema`, `CouncilVerdictSchema`, `ConsensusConfigSchema` with corresponding parse helpers and inferred types (`src/validation/schemas.ts`)
- **Test coverage** — 116 new tests across validation (61), renderer (22), consensus (29), and integration (4)

### Changed
