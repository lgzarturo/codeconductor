## Unreleased

### Added

- README: Socket.dev badge and Mermaid supply-chain graph for declared npm
  production dependencies (`zod`, `yaml`), expected CLI network/spawn
  capabilities, and a link to the live Socket dependency report.
- `/cc-security` (`/cc:security`): authorized defensive security workflow plus
  `security-*` skills (recon, assessment, IR, hunting, GRC, and related
  domains). Offensive exploit/malware content is out of scope.
- OpenSpec delivery loop: `openspec start`, `done`, `block`, and `archive`.
- `ccep consensus --input @verdicts.json` (exit 0/1/2) with quorum, required
  confidence, and `criticalFindingsPolicy`.
- `ccep taskcard --command <workflow> --input @card.json` intake gate.
- Coverage floor (`check:coverage` aggregate 70%) and stdlib `bun run lint`.
- `/cc-security` (`/cc:security`) — authorized defensive security workflow with
  an authorization gate and fix-style risk routing.

### Changed

- Replace remaining production `execSync(string)` with `execFileSync` argv
  (`scorecard` git diff, OpenSpec backlog scan, complementary-tool `which`/`where`).
- `install lsp --dry-run` reports would-install without probing `npm list -g` or
  `pip show` for already-installed servers.

### Fixed

- `council-verdict` validates the aggregated `CouncilVerdictSchema` and unknown
  CCEP output schemas fail closed.
- OpenSpec `plan` resets TaskCards whose backlog item snapshot hash drifted.
