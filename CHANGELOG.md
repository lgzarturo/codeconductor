## Unreleased

### Changed

- Parse native Claude and Antigravity hook stdin, replay input across runner
  fallbacks, normalize Windows paths and Git executables, and run local
  formatters through Node without npm shell shims. Claude permissions now
  default to `default`.
- Use the four requested OpenCode Go models with compatible permission rules and
  provider sampling defaults; correct Antigravity CLI model slugs.
- Use portable lowercase skill names across canonical, preset, and installed
  skills, with regression validation and hook CI on Linux, macOS, and Windows.

### Added

- Receipt-Driven Development receipts for local verification, TDD transitions,
  OpenSpec gates, ODD resumption, and Council candidate comparison.

- `/cc-security` (`/cc:security`) — authorized defensive security workflow with
  an authorization gate and risk-based routing.
- Shared `web-design-engineering` skill for contextual web UI design, implementation,
  and review across all seven runners, with conditional workflow references,
  accessibility and motion criteria, and explicit pending visual verification.
- Shared `android-ui-design` skill for contextual Jetpack Compose phone UI design,
  implementation, review, and read-only audits across all seven runners.
