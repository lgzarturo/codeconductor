## Unreleased

### Added

- New `/cc-spec-mutation` workflow (CCEP command `spec-mutation`): spec-locked
  TDD pipeline — interactive spec refinement, strict Gherkin contract frozen
  with SHA-256, three-laws TDD cycle, judge audit, and a deterministic
  mutation-testing gate. Ships `presets/shared/mutation_runner.py` (stdlib-only
  AST mutator, fail-fast hands-off with exit code 2, unconditional rollback)
  and presets for cursor, claude, opencode, agy, gemini, and codex. Surviving
  mutants route back to the TDD craftsman; a 3-iteration circuit breaker
  escalates to human arbitration.

### Changed

- OpenCode Go role slugs remapped to the current catalog (`mimo-v2.5`,
  `kimi-k3`, `qwen3.8-max`, `glm-5.3`, `gpt-5.6-luna`, `longcat-2.0`, `hy3`).
  Default TUI model is `opencode-go/qwen3.7-plus`. `muse-spark-1.2-contributor`
  is excluded from production roles.
- Agent hooks are OS-agnostic Node (`hook pre-tool|post-tool|session-start`);
  Claude and agy presets no longer embed bash/jq.
- Core workflow skills (`openspec`, `backlog`, `evaluation`, `testing-tdd`)
  follow process + anti-rationalization + verification, and invoke CLI gates.

### Added

- `/cc-security` command and security preset for backend security workflows.
- `scorecard suite-run` plus suites `hook-guardrails`, `workflow-gates`,
  `scorecard-signals`.
- Meta skill `using-cc-skills` and agent Composition blocks on living contracts.
- `docs/hooks.md`.
