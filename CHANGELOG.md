### Added

- **AgentContract abstraction** — provider-agnostic contract type (`AgentContract`, `createAgentContract()`) that wraps a `CouncilSpec` with targeting and versioning metadata (`src/domain/council/agent-contract.ts`)
- **`toAgentContract()` helper** — convenience function on `CouncilSpec` to convert a spec into an `AgentContract` for one or more targets (`src/domain/council/council-spec.ts`)
- **Council consensus engine** — pure function `councilConsensus()` that computes a verdict from N reviewer agents using majority or unanimous algorithms, with security veto support (`src/domain/council/council-consensus.ts`)
- **`AgentContractRenderer` interface** — strategy interface for rendering an `AgentContract` into provider-specific files (`src/core/generation/agent-contract-renderer.ts`)
- **`ClaudeAgentContractRenderer`** — renders contracts into `.claude/` structure with format validation (`src/adapters/claude/agent-contract-renderer.ts`)
- **`OpenCodeAgentContractRenderer`** — renders contracts into `.opencode/` structure with frontmatter and format validation (`src/adapters/opencode/agent-contract-renderer.ts`)
- **Zod validation schemas** — `AgentContractSchema`, `CouncilVerdictInputSchema`, `CouncilVerdictSchema`, `ConsensusConfigSchema` with corresponding parse helpers and inferred types (`src/validation/schemas.ts`)
- **Test coverage** — 116 new tests across validation (61), renderer (22), consensus (29), and integration (4)
