# Installation

Run CodeConductor from a project directory with Node 20.11+ or Bun.

```bash
npx cc-codeconductor setup --target claude --locale es --yes
```

Use `--dry-run` first when you want to inspect the files without changing the
project. `setup` is the onboarding command; `init` and `install` remain useful
low-level primitives for advanced automation.
