# CodeConductor v0.5.0 — Release Notes

**Status:** Agent contract prompts shipped (package version bump is separate).

v0.5.0 aligns bundled **Agent Contracts** with the Evaluation features already
implemented in the CLI (scorecard, outcome tracking, prompt-diff, regression
checklist, model comparison, cost/quality matrix).

---

## Prompts and contracts v0.5.0

The canonical archive lives at `presets/opencode/prompts/v0.5.0/` (12 files).
Install copies them to each target under `prompts/v0.5.0/`.

### What changed from v0.4.0

| Area | Change |
| ---- | ------ |
| **Evaluation Gate** | Orchestrator runs scorecard create/record after medium/high-risk deliverables |
| **New agents** | `security-reviewer`, `goal-planner`, `contract-builder` prompts + active agents |
| **Cursor orchestration** | Target-Specific Orchestration (`/multitask`, model tiers, background subagents) |
| **Context scope** | `isolated` uses `/clear` (aligned with Cursor) |
| **Grok fallback** | `{{MODEL_GROK}}` in model tables; `cursor-grok-4.5-high-fast` on Cursor preset |
| **Reviewer** | Scorecard integration (8 criteria, PASS/REVISE/REJECT mapping) |
| **Codex AGENTS.md** | `contract-builder` section + DDD→SDD→TDD routing row |

### New prompt files

- `security-reviewer.md` — dedicated security review with veto authority
- `goal-planner.md` — YAML task graph from objective strings
- `contract-builder.md` — DDD→SDD→TDD API contract specs

---

## Migration

1. Re-run install for your target:

   ```bash
   npx cc-codeconductor install preset --target=<opencode|claude|cursor|codex|gemini> --force
   ```

2. Bump `contract_version` in `codeconductor.config.jsonc`:

   ```jsonc
   "contract_version": "0.5.0"
   ```

3. Compare contract drift:

   ```bash
   npx cc-codeconductor scorecard prompt-diff 0.4.0 0.5.0 --agent orchestrator
   ```

4. v0.4.0 prompts remain in the archive (deprecated, not deleted).
