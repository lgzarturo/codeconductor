# CodeConductor v1.3.0 — Release Notes

**Release date:** 2026-09-11  
**Status:** Stable  
**Version line:** 1.3.x (current package: `1.3.0`)

CodeConductor v1.3.0 is the current stable release. It keeps the v1.0.0
workflow contract baseline and improves the reliability and parity of the
bundled runner presets.

## Highlights

- **Cross-target command rendering** — Cursor workflow sources now render
  correctly for Gemini and Codex, including line-ending normalization,
  descriptions, command references, and target-appropriate role instructions.
- **Runner parity** — the seven supported targets (Claude, Codex, Cursor,
  Gemini, OpenCode, AGY, and Pi) receive the relevant preset assets. Council
  installation covers Gemini and Cursor, and Gemini receives the complete shared
  skill set.
- **Centralized skill versions** — `skills-registry.json` is the source of truth
  for skill versions, with synchronized canonical copies across supported
  presets.
- **Workflow continuity** — workflow commands name their next step where one
  exists, and generated council agent files include role-specific review
  checklists and the existing finding severities.
- **Web design engineering** — web interface work can use the shared
  `web-design-engineering` skill for contextual layout, component states,
  accessibility, motion decisions, and evidence-based UI review. It activates
  for concrete web UI scope and does not change CCEP contracts, review axes,
  scorecard weights, or native mobile workflows.

## Compatibility and fixes

This release fixes preset installation and generation issues that could leave
descriptions truncated, cross-target command syntax invalid, council assets in
the wrong runner directory, or AGY hook output unparsable. It also keeps the
existing v1.0.0 prompt contract archive; the package version and prompt contract
version are separate concerns.

## Upgrade

Reinstall the preset for each runner you use so generated files and the shared
skill library are refreshed:

```bash
npx cc-codeconductor@1.3.0 install preset --target=<claude|codex|cursor|gemini|opencode|agy|pi> --force
```

During local development, use the equivalent `bun run dev install preset ...`
command. Existing project configuration and v1.0.0 prompt references remain
valid.

## Verification

The release is checked by the preset, synchronization, frontmatter, command
rendering, two-axis review, and seven-runner installation tests. Visual browser
checks for a particular web interface remain part of that task's acceptance
criteria and must be recorded as pending when no browser is available.
