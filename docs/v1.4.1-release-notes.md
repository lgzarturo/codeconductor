# CodeConductor v1.4.1 — Release Notes

**Status:** Unreleased

## ODD adoption gate

ODD is still opt-in. The new `odd-adoption` scorecard suite compares paired
tracked ODD and OpenSpec samples on acceptance, test passes, findings, context,
and reported cost. ODD can be recommended by default only after that evidence
is non-inferior on quality and shows lower context; unavailable cost remains
`unknown` rather than a claimed saving.

See [ODD adoption evaluation](odd-adoption.md) for the criteria, the command,
resumption from the Delivery Ledger, and escalation to OpenSpec, TDD, or
Council.
