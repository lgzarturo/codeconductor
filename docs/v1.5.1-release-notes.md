# CodeConductor v1.5.1 — Release Notes

**Release date:** 2026-09-30  
**Status:** Stable  
**Version line:** 1.5.x (current package: `1.5.1`)

CodeConductor v1.5.1 ships cheaper subagent delegation, a transcript-free
handoff path for interrupted work, safer installs, and hardened hooks. It
keeps the v1.0.0 workflow contract baseline.

## Highlights

**CCEP compilation views and telemetry.** `ccep compile --view
prompt|layers|full` selects the returned representation (`full` stays the
compatible default), and `--record-telemetry` appends a local
`context.compiled` event with prompt/layer byte sizes. Slash-command Step 0
now runs one `ccep compile --view prompt` per delegated phase and forwards
only the role-scoped prompt, so subagents receive filtered knowledge instead
of the full resolve context. See [CCEP](CCEP.md).

**ODD command and handoff envelope.** New `odd create|read|reconcile`
commands plus `odd handoff --id <delivery-id>`, which derives a compact,
transcript-free envelope (objective, acceptance criteria, constraints,
files, evidence, next action) from the Delivery Ledger and working-tree
divergence. `/cc:handoff` uses the envelope when a ledger exists. ODD stays
opt-in pending the `odd-adoption` evidence gate. See
[ODD adoption](odd-adoption.md).

**Safer installs.** New `create-only` manifest strategy: write only when the
destination is missing, never overwrite (even with `--force`). The Codex
council install no longer drops `[agents.*]` tables when the preset is
reinstalled.

**Model routing and token budgets.** Claude work routes through Sonnet 5.5
with Haiku for discovery/routing and Opus 5.5 reserved for scoped
architecture escalation; Codex presets and council use GPT-6.1 Sol at medium
reasoning effort with concise handoffs. The Claude preset sets
`effortLevel: "medium"`, disables the agent-teams experiment, and no longer
injects MCP servers into `settings.json`.

**Hardened hooks.** Destructive-command rules extend to PowerShell
(`Remove-Item`, `rd`, `del`, quoted `git.exe`); `.env.example` stays
readable while other `.env*` paths are denied; hook stdin is parsed
natively per runner and replayed across fallback runners. See
[hooks](hooks.md).

## Compatibility and fixes

- ODD ledger requests reject absolute or `..` `technicalPlanPath` values.
- Windows path handling uses `basename()`/`relative()` instead of
  string surgery; `.gitattributes` enforces `eol=lf`.
- Portable lowercase skill names across canonical, preset, and installed
  copies; `security-*` skills extended to Codex.

## Upgrade

Reinstall the preset for each runner you use so generated files and the shared
skill library are refreshed:

```bash
npx cc-codeconductor@1.5.1 install preset --target=<opencode|claude|codex|gemini|cursor|agy|pi> --force
```

During local development, use the equivalent `bun run dev install preset ...`
command. Existing project configuration and v1.0.0 prompt references remain
valid.

## Verification

The release is covered by the full `bun test` suite (CCEP compiler and
telemetry, ODD ledger and envelope, file-copier strategies, hook
portability, preset synchronization, and per-target installation tests),
`tsc --noEmit`, `lint`, and the preset drift check.
